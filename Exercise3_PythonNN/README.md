While it is possible to write very simple neural networks suing the default records in EPICS more realistic cases may rely on external frameworks. In this step the students will install AutoGluon (https://auto.gluon.ai/stable/tutorials/timeseries/forecasting-quick-start.html) and train their model using of of the sample datasets from the AutoGluon project. Then they install p4p and make an EPICS server that can accept data as an EPICS array PV and feedback the result in another EPICS array PV. Demosntrate that the solution works.
